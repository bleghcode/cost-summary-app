Cost Summary (แอปใบสรุปต้นทุนทัวร์)

วิธีใช้แบบง่าย (ไม่ต้องติดตั้งอะไร)
  ดับเบิลคลิก index.html เปิดด้วย Chrome หรือ Edge ใช้ได้ทั้งออนไลน์/ออฟไลน์
  ข้อมูลบันทึกในเครื่องอัตโนมัติ ปิดแล้วกลับมาทำต่อได้ที่รายการด้านซ้าย
  ควรเปิดจากไฟล์ที่เดิมทุกครั้ง (อย่าย้ายหรือเปลี่ยนชื่อโฟลเดอร์ ไม่งั้นเบราว์เซอร์อาจมองเป็นคนละที่และไม่เห็นข้อมูลเดิม)

วิธีติดตั้งเป็นแอป (ปุ่มติดตั้งในแถบที่อยู่ / Add to Home Screen บนมือถือ)
  ต้องวางโฟลเดอร์นี้บนเว็บ https เช่น GitHub Pages / Netlify / Cloudflare Pages
  (อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้) แล้วเปิดลิงก์นั้นหนึ่งครั้งตอนออนไลน์
  หลังจากนั้นเปิดตอนออฟไลน์ได้ และใช้เป็นไอคอนบนเครื่องได้
  ถ้าแก้ index.html ภายหลัง ให้เปลี่ยน VERSION ใน sw.js (เช่น v1 -> v2) เพื่อให้เครื่องดึงของใหม่

สำรองข้อมูล (สำคัญ)
  ข้อมูลอยู่ในเบราว์เซอร์ของเครื่องนี้เท่านั้น ถ้าล้างข้อมูลเบราว์เซอร์ / เปลี่ยนเครื่อง / ใช้โหมดส่วนตัว จะหาย
  กด "สำรองข้อมูลทั้งหมด" เป็นระยะ เก็บไฟล์ .json ไว้ แล้วใช้ "นำเข้าจากไฟล์สำรอง" เพื่อกู้คืนหรือย้ายไปเครื่องอื่น

ฟีเจอร์เพิ่มเติม (v2)
  - ชื่อไฟล์ PDF: GP_000_MM_ชื่อลูกค้า_Cost Summary  โดย MM = เดือนเดินทาง (วันเริ่มต้นใน Travel Date)
  - แสดงจำนวนคืน/วัน (เช่น 4N 5D) ข้างช่อง Travel Date
  - ช่อง Description พิมพ์แล้วเลือกจากรายชื่อได้ ถ้าเป็นชื่อใหม่กด "+ เพิ่ม" เข้ารายการทันที
    จัดการ/แก้ชื่อ/เพิ่มทีละหลายชื่อ ได้ที่เมนูซ้าย "จัดการรายชื่อ"
  - มีช่อง Type (ประเภท) ก่อนช่องราคา เฉพาะหมวด Transportation ระบบจำประเภทที่เคยใช้กับแต่ละชื่อไว้แนะนำครั้งหน้า
  - ไฟล์สำรอง .json รวมรายชื่อทั้งหมดไว้ด้วย
